# 🍄 ГрибБот — Telegram-бот распознавания грибов

Релизная версия. Бот принимает фотографию гриба и через нейросетевой API
[Kindwise Mushroom ID](https://www.kindwise.com/) определяет вид, съедобность и
особенности, выдавая предупреждения об опасных видах.

> ⚠️ Результаты носят информационный характер. Бот **не** является заменой
> консультации миколога и не должен использоваться как единственное основание
> для употребления грибов в пищу.

---

## Возможности

- Распознавание гриба по фото (и по картинке-документу)
- Народные названия, съедобность, токсичность, описание — на русском
- Вывод альтернативных вариантов (важно для ядовитых двойников)
- Предупреждение ☠️ при опасных видах и пометка о низкой уверенности
- Команды: `/start`, `/help`, `/status`

## Надёжность (заложено в код)

- **Повторы с задержкой** при таймаутах, сетевых сбоях и ошибках 429/5xx
- **Типизированная обработка ошибок** API: неверный ключ, исчерпан лимит,
  перегрузка, битое изображение, недоступность сервиса — каждому своё сообщение
- **Анти-спам**: ограничение числа запросов на пользователя
- **Лимит размера** изображения
- **Безопасный HTML** с экранированием (имена/описания со спецсимволами не ломают ответ)
- **Глобальный обработчик ошибок** — бот не падает на необработанных исключениях
- **Корректный выход** при отсутствии ключей (понятное сообщение, код возврата 2)

## Структура

```
bot.py            — точка входа, хендлеры Telegram
config.py         — настройки из переменных окружения с валидацией
mushroom_api.py   — клиент Kindwise API (повторы, типы ошибок)
formatting.py     — формирование ответа (HTML, экранирование, безопасность)
rate_limiter.py   — анти-спам
requirements.txt  — зависимости (зафиксированы)
.env.example      — шаблон конфигурации
Dockerfile, docker-compose.yml, gribbot.service — варианты развёртывания
tests/            — автотесты (34 шт.)
```

## Подготовка

1. Получите **TELEGRAM_TOKEN** у [@BotFather](https://t.me/BotFather): `/newbot`.
2. Получите **MUSHROOM_API_KEY** на [admin.kindwise.com](https://admin.kindwise.com/).
3. Скопируйте шаблон и заполните ключи:
   ```bash
   cp .env.example .env
   nano .env
   ```

> 🔐 Файл `.env` не коммитьте в Git (он уже в `.gitignore`).

## Запуск: вариант A — Docker (рекомендуется)

```bash
docker compose up -d --build      # собрать и запустить в фоне
docker compose logs -f gribbot    # смотреть логи
docker compose restart gribbot    # перезапустить
docker compose down               # остановить
```

`restart: unless-stopped` обеспечивает автоподъём после сбоя или перезагрузки сервера.

## Запуск: вариант B — systemd (без Docker)

```bash
sudo useradd -r -s /usr/sbin/nologin gribbot
sudo mkdir -p /opt/gribbot && sudo cp -r * /opt/gribbot/ && cd /opt/gribbot
sudo python3 -m venv venv
sudo venv/bin/pip install -r requirements.txt
sudo cp .env /opt/gribbot/.env            # с заполненными ключами
sudo chown -R gribbot:gribbot /opt/gribbot

sudo cp gribbot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gribbot
sudo systemctl status gribbot             # проверить
journalctl -u gribbot -f                  # логи
```

## Запуск: вариант C — вручную (для проверки)

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## Настройки (необязательные, см. `.env.example`)

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `REQUEST_TIMEOUT` | 30 | таймаут запроса к API, сек |
| `MAX_RETRIES` | 3 | число повторов при сбоях |
| `RETRY_BACKOFF` | 1.5 | базовая задержка повтора, сек |
| `MAX_IMAGE_BYTES` | 12582912 | макс. размер фото (12 МБ) |
| `RATE_LIMIT_COUNT` | 5 | запросов на пользователя |
| `RATE_LIMIT_WINDOW` | 60 | за столько секунд |
| `CONFIDENCE_THRESHOLD` | 0.80 | порог надёжности результата |
| `LOG_LEVEL` | INFO | уровень логирования |
| `LOG_FILE` | — | путь к файлу лога (пусто = консоль) |

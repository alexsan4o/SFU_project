# Вариант 10 — обход шахматной доски конём

**Задача:** построить маршрут коня, который посещает каждую клетку доски ровно один раз.

Решение написано на Python 3 и работает с прямоугольными досками. По умолчанию ищется открытый обход стандартной доски 8 × 8, начинающийся в клетке A1. Дополнительно можно запросить замкнутый обход (последняя клетка маршрута должна быть доступна коню из первой).

## Запуск

```bash
python3 knights_tour.py
python3 knights_tour.py --rows 8 --cols 8 --start-row 1 --start-col 1
python3 knights_tour.py --rows 8 --cols 8 --closed
```

Координаты в аргументах командной строки нумеруются с единицы. Программа печатает доску с номерами ходов. Если маршрут для заданных параметров не найден, она сообщает об этом и завершается с кодом 1.

Функцию можно также использовать из другого Python-кода:

```python
from knights_tour import solve_tour

route = solve_tour(8, 8, start=(0, 0), closed=False)
```

В программном интерфейсе координаты начинаются с нуля; результат — список пар `(строка, столбец)` или `None`.

## Идея алгоритма и корректность

Доска представляется графом: каждая клетка — вершина, а ребро соединяет клетки, между которыми конь может сделать ход. Требуется найти гамильтонов путь (или цикл, если указан `closed=True`) этого графа.

Используется полный поиск с возвратом: на каждом шаге перебираются все ещё не посещённые клетки, достижимые одним ходом коня. Если продолжить маршрут невозможно, алгоритм возвращается к предыдущему выбору и пробует следующий. Порядок вариантов задаёт правило Варнсдорфа: раньше проверяются клетки с меньшим числом доступных дальнейших ходов. Это лишь эвристика порядка перебора — она не отбрасывает ветви, поэтому поиск остаётся полным: если маршрут существует, перебор его найдёт.

Перед возвратом результат содержит ровно `rows × cols` различных клеток; каждый соседний элемент списка связан допустимым ходом коня. Для замкнутого обхода дополнительно проверяется допустимость хода из последней клетки в первую.

## Оценка сложности

Пусть `V = rows × cols` — число клеток. У каждой вершины не более восьми соседей. В худшем случае поиск перебирает экспоненциальное число частичных маршрутов: время `O(8^V)`. Сортировка кандидатов выполняется среди максимум восьми ходов и не меняет эту оценку. Память — `O(V)` на стек поиска, массив посещённости и маршрут (без учёта списка смежности, который также занимает `O(V)`, поскольку степень вершин ограничена константой 8).

Экспоненциальная худшая оценка неизбежна для такого общего перебора гамильтоновых путей; порядок Варнсдорфа на обычной шахматной доске резко сокращает фактическое число проверяемых вариантов, но не даёт полиномиальной гарантии для любых размеров и начальных клеток.
